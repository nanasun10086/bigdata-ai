# 大数据与人工智能 · 课程仓库

本仓库用于《大数据与人工智能》课程的学习、笔记、实验与项目。

## 目录结构

```
大数据与人工智能/
├── README.md          # 本说明文件
├── .gitignore         # Git 忽略规则
├── notes/             # 课堂笔记
├── notebooks/         # Jupyter / Python 实验
├── assignments/       # 课程作业
├── data/              # 数据集（一般不提交到仓库）
└── projects/          # 个人项目
```

## 快速开始

```bash
# 克隆本仓库到本地
git clone https://github.com/<你的用户名>/<仓库名>.git

# 进入仓库目录
cd <仓库名>

# 查看状态
git status

# 添加所有改动到暂存区
git add .

# 提交改动
git commit -m "添加课程初始文件"

# 推送到远程 GitHub
git push
```

## 说明

- 使用 **Python 3.12** 进行数据分析与 AI 实验
- 推荐使用 **VS Code** 打开本仓库并安装 Python / Jupyter 扩展
